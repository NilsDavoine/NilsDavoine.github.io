In production

Two retrieval assistants for an accounting firm in Luxembourg, used by its staff since August 2026. The code and the documents are the firm's and stay private.

Document assistant

Staff ask questions in French, English or German and get answers from the firm's PDFs, e-mails and scans. Pages are read by OCR and split by section with a context prefix. Retrieval is hybrid: BM25 and pgvector, fused by Reciprocal Rank Fusion, then reranked. Access rights are applied inside the retrieval query.

One real failure shaped it: two documents said 25.5 and 26, and an answer said 25. Ranking and the cross-source number checks were rebuilt after it.

Onboarding assistant

Guides new staff through the firm's procedures, manuals, templates and FAQ, a few hundred documents. Each chunk is one procedure step, and the assistant remembers where the newcomer is in their path. HR documents are excluded from the index.

Public work

Rebuilt from scratch on invented data, after systems I built for real use. Each one says what it measures, and every number comes from a script in the repository.

  • rag-accounting-docs

    Hybrid RAG over invented FR/EN/DE accounting documents, with refusals, number-conflict checks and per-company isolation tested by breaking it on purpose.

    Reranking lifts MRR@8 from 0.68 to 0.98. On a harder held-out set, answer accuracy falls to 52.5 %, published as is. 0 passages from another company.

  • rules-vs-llm-filing-bench

    Hand-written rules against small local LLMs for naming and filing accounting documents. Measure before adding AI.

    Rules: 88 % exact on unseen pieces in about 1 ms. Qwen2.5-1.5B: 24 % in 10.9 s.

  • llm-structured-requests

    One sentence to a structured client request: strict schema, closed document list, personal data removed before the model is called.

    0 personal data sent across 60 FR/EN/DE cases. 85 % valid output after one repair with a 1.5B local model.

  • invoice-ocr-local

    Scanned invoices read on your own machine, checked for coherence and exported as EN 16931 / UBL XML, or set aside for a person.

    On 30 unseen invoices, 63 to 67 % fully right, and none exported wrong: every miss was set aside for a person.

  • multi-agent-video-pipeline

    Agents with typed contracts turn a brief into a short explainer video. Quality gates on the finished file decide if it can be published.

    Example passes with a word error rate of 1.6 %. One off-script scene: blocked.

  • agir-client-portal-demos

    Playable replicas of the client portal and staff workstation, built from the real page templates and scripts with a fake server inside the page.

    18 demos, including drafting a client request with an LLM.

How these were built: I set the architecture, the measurements and the acceptance criteria, and used Claude Code as a coding agent to write most of the code to that brief. The guardrails are tested by mutation: each one is broken on purpose to check that its test fails.
